# रास्ते कटे (Raste Kate) — सफ़र का संगीत 🛣️🎵

> **"सफ़र पर हो तो गाना साथ हो"** — A minimalist, mood-aware Indian travel radio web app playing non-stop Hindi, Punjabi, Bhojpuri, 90s Romantic, and Item hits for road trips, bus rides, train journeys, and flights.

![Raste Kate Preview](hero.jpg)

## ✨ Features

- 🚗 **Safar Mode Selector**: Switch effortlessly between **सड़क** (Road), **बस** (Bus), **रेल** (Train), and **हवाई** (Flight).
- ⚙️ **Vibe & Mood Filter**: Choose by Era (90s Retro, 2000s Hits, Latest Trending) and Mood (Romantic Love Songs, Item & Dhaba Beats, Chill Road Trip & Sufi, Punjabi Highway Beats, Bhojpuri Tadka).
- ♾️ **Infinite Radio Engine**: 100+ curated anthems with dynamic auto-reshuffle so the music never stops.
- 🎨 **Rich Indian Highway Aesthetics**: Illustrated golden-hour highway backdrop, vinyl record animation, dynamic beat equalizer, and canvas highway dust particles.
- 🕐 **Live IST Clock & Listener Simulation**: Feel the shared experience of travel radio.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (installed on your system)

### Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Jaydeep12-3/rastekate.git
   cd rastekate
   ```

2. **Start the local server:**
   - On Windows: Double-click `Start-RasteKate.bat` or run:
   ```bash
   node server.js
   ```

3. Open your browser and navigate to:
   ```
   http://localhost:9001
   ```
